# 🦆 QUACK.

> A completely unnecessary 3D duck that exists solely to quack when you click it.

## What is QUACK?

QUACK. is a tiny interactive web experience featuring a 3D rubber duck.

There is no complicated purpose.

There is no productivity benefit.

There is just a duck.

**Click the duck → it quacks. 🦆🔊**

## ✨ Features

- 🦆 Interactive 3D rubber duck
- 🔊 Real duck-quacking sound
- 💥 Duck bounce and wiggle animation
- 💬 Animated `QUACK!` feedback
- 🖱️ Mouse and touch interaction
- 🔢 Quack counter
- 🎨 Minimal dark-themed interface
- 📱 Responsive design
- ⌨️ Keyboard interaction

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Three.js
- Vite

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/manish23092003/Duck.git
cd Duck
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
